# 游戏内临时战斗

1. 正常运行游戏，进入备战界面，点击右上方的“临时战斗”。不需要创建或切换 Unity 编辑器场景。
2. 和搜打撤出战一样经过 Loading，进入 Battle WorldZone，并显示战斗主 UI。
3. 测试地图只有一层平坦地面；默认生成满血战士（Robot ID 1），初始没有敌人。
4. 左上测试面板点击“主角”循环选择角色，再点“切换 / 重置”。这会清空测试敌人，以所选主角重新开始。
5. 点击“敌人”切换 BattleEnemy 模板，再点“新增一只敌人”。每次只追加一只，生成在玩家前方附近，不重建已有角色，不重置其 AI、动作或技能冷却。
6. 使用正常战斗操作；动作、普通攻击、技能、敌人 AI 都走正式配置和运行时。
7. 点击“返回备战”恢复进入前的备战数据。玩家死亡或通过设置放弃测试也会返回，不执行正式失败损失和维修。

## 数据隔离

- 不消耗玩家机器人和库存；测试主角使用无装备基础模板。
- 复用正式 SaveRuntime 的时钟、Loading、WorldZone 和战斗 Normal，不再注册独立测试时钟。
- 测试使用独立内存会话，自动存档、手动存档及候选写盘全部被禁止。
- 返回时恢复原会话，包括进入前尚未保存的改动；不从磁盘重新加载旧档。
- 临时敌人不生成正式掉落，不接入搜刮和正式撤离结算。停止游戏会丢弃测试数据。
- 敌人必须关联合法 AI Profile 和已发布行为图；缺配置时明确报错，不回退旧 AI。

## 预制体和日志

- 备战入口：`gui/ui_game/win_battle_preparation.prefab`，沿用已有按钮引用。
- 测试面板：`gui/ui_game/win_battle_world_zone.prefab` 下的 `BattleSandboxControls`，通过 `BattleSandboxHud` 显式绑定。
- 编译后会增量补齐这两处，不重建其它预制体或场景。必要时可用菜单 `TryGame → 战斗 → 补齐游戏内临时战斗界面`。
- Console 使用 `[BattleSandbox]` 前缀；战斗和行为树继续输出原有诊断日志。
